# Codex Usage Monitor 1.0.0

Primera versión estable de Codex Usage Monitor para Windows.

## Incluye

- Monitor de uso de Codex para las ventanas de 5 horas y 7 días.
- Porcentaje usado, countdown basado en `resetsAt` y disponibilidad ordinaria.
- Reset credits visibles únicamente como información.
- Modos completo y compacto, Always-on-top, bandeja e instancia única.
- Inicio opcional con Windows e instalación por usuario sin UAC.
- Detección automática de una instalación compatible de Codex y recuperación
  cuando Codex aparece mientras el monitor está abierto.
- Funcionamiento local sin telemetría, analytics ni servidores propios.

## Limitaciones conocidas

- Requiere Windows 10 u 11 de 64 bits.
- Requiere una instalación compatible de Codex para mostrar datos de uso.
- Los binarios no están firmados digitalmente y pueden activar SmartScreen.

Codex Usage Monitor is an unofficial community project and is not affiliated
with or endorsed by OpenAI.
